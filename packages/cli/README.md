# @jackkoskie/docengine

Docs-as-code for structured policy documents: validate Markdown and generate Typst PDFs and manifests.

```sh
pnpm add -D @jackkoskie/docengine
pnpm exec docengine --help
```

PDF generation also requires the [Typst CLI](https://typst.app/). See the [getting-started guide](https://github.com/jackkoskie/docengine/blob/main/docs/GETTING-STARTED.md) and [repository](https://github.com/jackkoskie/docengine) for documentation.
